Tic Tac Toe - Kotlin Android Game
Welcome to Tic Tac Toe, a classic game reimagined in Kotlin with a modern Android design!
Challenge your friends, track your scores, and see who claims the crown 👑.

🎯 Overview
This project is a simple yet polished two-player Tic Tac Toe app built using Android Studio (Edge).
It features a smooth UI, real-time turn updates, and an intuitive scoreboard — all running fast even on low-end devices.

⚡ Features
✅ Two-player mode (Cross ❌ vs Nought ⭘)
✅ Auto win detection and draw logic
✅ Score tracking between rounds
✅ Instant board reset
✅ Clean, responsive layout for all screens

🧩 Tech Stack
Component	Description
🧠 Language	Kotlin
🖌️ UI Layout	XML (ConstraintLayout + LinearLayout)
🎨 Styling	Custom styles & themes
🧰 IDE	Android Studio Edge / Koala
📱 Min SDK	24+
